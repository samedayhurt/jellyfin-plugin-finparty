FinParty

Keeps Jellyfin SyncPlay from stalling over Tailscale, WireGuard and other high-latency links. It runs by itself — there is nothing to start. Whenever a SyncPlay group is active, FinParty measures the round-trip time to each member and widens Jellyfin's timing tolerances to match, and it stops one buffering device from freezing the group.

Latency tuning

Jellyfin hard-codes a 500 ms playback tolerance. Over a relayed VPN link that is violated constantly, which is what causes the endless re-seeking and stalls. Adaptive measures each group's real round-trip time and widens the tolerance only as much as needed.

Keeping the group moving

If someone's stream stalls, the rest of the group carries on and that device rejoins automatically once it catches up. Uses SyncPlay's own "stop waiting for me" request.
