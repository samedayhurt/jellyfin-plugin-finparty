FinParty

Watch parties that survive Tailscale, WireGuard and other high-latency links. The family-facing remote lives at /FinParty — send that link to anyone who should be able to start a party.

Latency tuning

Jellyfin hard-codes a 500 ms playback tolerance. Over a relayed VPN link that is violated constantly, which is what causes the endless re-seeking. Adaptive measures each party's real round-trip time and widens the tolerance only as much as needed.
How far a client may drift before the server drags it back. Jellyfin's value is 500.
Beyond this skew the server discards the client's own timestamp, which makes every correction worse. Jellyfin's value is 2000.
Stops one pathological connection from making the whole party sloppy.

Keeping the party moving

If someone's stream stalls, the rest of the party carries on and that person rejoins automatically once they catch up. Uses SyncPlay's own "stop waiting for me" request.
